# Hall of Chairs 🪑

A fun fan-made fortune teller inspired by [The Mutual Fun](https://themutual.fun).

Spin the chairs and discover which seat the universe has reserved for you.

---

### How to use
1. Click **Enter the Hall**
2. Spin for your Chair
3. Share your result on X
